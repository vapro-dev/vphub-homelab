# VPHUB Homelab — ficha de portfolio

## Resumen corto

Diseño e implementación de una infraestructura de laboratorio personal con routing, DNS interno, NAT, virtualización Proxmox y administración segura de equipos Linux mediante SSH con llaves.

## Problema resuelto

Necesitaba un entorno aislado y ordenado para practicar infraestructura real, sin afectar la red de uso cotidiano. Diseñé una LAN propia detrás de un router MikroTik, centralicé los equipos mediante un switch administrable, preparé un host Proxmox y normalicé el acceso administrativo.

## Tecnologías utilizadas

- MikroTik RouterOS
- Proxmox VE
- Debian Linux y Arch Linux
- SSH / Ed25519
- DNS, DHCP y NAT
- Switching administrable
- Git y documentación Markdown

## Habilidades demostradas

- Diseño de topología e inventario de infraestructura.
- Troubleshooting basado en evidencia.
- Administración remota segura.
- Normalización de redes en hypervisores.
- Documentación técnica y sanitización para publicación.
- Planificación de backups y escalabilidad.

## Aprendizaje principal

Una infraestructura pequeña también requiere método: relevamiento, cambios controlados, validación, documentación y respaldo.
